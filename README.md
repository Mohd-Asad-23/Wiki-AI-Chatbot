# Wikipedia Quiz Generator

Open Source Day – Project Challenge. Team name: **<your team name>**
Track: **<Kaggle / Build with Open Source>**

An app that creates multiple-choice and true/false trivia from the
**Wikimedia Structured Wikipedia Dataset (Kaggle)**. No other dataset is used.

## What it does
| Question type | How it is made |
|---|---|
| Fill the blank | A sentence from an article's abstract with the title replaced by `_____`; pick the right article from 4 options. |
| Short description | Show an article's short description; pick the matching article. |
| Infobox facts | Ask for an infobox value (e.g. Capital); wrong options are real values of the same field from other articles. |
| True / False | A real abstract sentence (true) or the same sentence with the subject swapped for another article's title (false). |

Extras: topic filter (search), dark-mode friendly (follows your Streamlit theme),
accuracy-by-type chart, answer explanations with a link to the source article,
review of mistakes at the end.

The questions are generated by plain rules, with no AI API, so every step is
explainable and repeatable.

## Run it
1. Download the dataset from Kaggle and unzip it. Use a `.jsonl` or `.json` file
   (a small sample file is fine for a demo).
2. Install and start:
   ```
   pip install -r requirements.txt
   streamlit run app.py
   ```
3. In the sidebar, paste the file path (or upload a file), optionally type a topic
   filter, and press **Start new quiz**.

Check the engine without the UI: `python test_engine.py`
(uses small synthetic records for testing only).

## Files
- `quiz_engine.py` – loading and question generation (pure Python).
- `app.py` – Streamlit interface, scoring and chart.
- `test_engine.py` – unit tests.

## Known limitations
- A "false" statement made by swapping the subject can occasionally still be true.
- Blank questions need the title to appear in an abstract sentence, so some
  articles are skipped.
- Infobox questions depend on infobox data being present and on field names that
  repeat across articles.
- Very large files are read as a stream, but only the first N matching articles
  are used (set in the sidebar).
